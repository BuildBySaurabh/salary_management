# AI-assisted development

AI was used as an engineering accelerator and review partner.

## Examples
- Turn the assessment into an MVP, explicit scope and non-goals.
- Review the relational data model and useful indexes.
- Generate initial DRF serializer/view boilerplate.
- Review React component boundaries and reusable UI patterns.
- Generate tests for auth, employee CRUD, search and dashboard aggregation.
- Review error handling and deployment configuration.

## Human verification
The final implementation should be checked by running migrations, seed data, backend tests, frontend build/tests and manual end-to-end flows.

The intended workflow is **plan → generate a small piece → inspect → run → test → integrate → commit**, rather than one giant AI-generated commit.
